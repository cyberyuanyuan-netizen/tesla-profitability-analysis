# Tesla Profitability Analysis

## Project Overview
This project analyzes Tesla's declining profit margins despite increasing vehicle deliveries. The objective is to identify the primary drivers behind margin compression using financial data analysis.

## Business Question
Was Tesla's declining profitability mainly driven by aggressive price reductions or rising production costs?

## Methodology
- Python
- Pandas
- Financial Data Analysis
- Regression Analysis
- Correlation Analysis
- Data Visualization

## Key Findings
- Average revenue per vehicle declined faster than production cost per vehicle.
- Profit margin compression was primarily driven by pricing strategy rather than manufacturing costs.
- Increasing sales volume alone was insufficient to improve profitability.
